# my-website
My first personal website

*** プロジェクトについて ***

このプロジェクトは、Javaを使って作成した座席予約システムです。
このプログラムでは、全部で50席を管理します。利用者は、空席の確認、座席の予約、予約のキャンセルができます。

主な機能
空席確認：50席の空席と予約済みの席を確認できます。
座席予約：座席番号を選び、料金を確認してから予約できます。
料金設定：座席番号によって、5,000円、7,000円、10,000円の料金を設定しています。
予約キャンセル：予約した座席をキャンセルできます。
売上表示：プログラムを終了するときに、合計売上を表示します。
